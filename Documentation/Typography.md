# Typography

CMS admin chrome uses Google Fonts. Emoji fall through to the system color-emoji fonts.

## Font Stack

| Use | Font | Weight | Style | Case |
|-----|------|--------|-------|------|
| **Buttons** | Cabin | 700 | — | Sentence |
| **Labels** | Archivo Expanded | 700 | — | All caps |
| **Body/Descriptions** | Cabin Medium | 500 | — | Sentence |
| **Post editor** | Inter | 400–500 | lining figures | Sentence |
| **Headline** | Archivo Expanded | 800 | — | All caps |
| **Subheader** | Archivo Expanded | 500 | — | All caps |

## CSS Classes

- `.font-button` — Cabin Bold
- `.font-label` — Archivo Expanded Bold, uppercase
- `.font-body` — Cabin Medium
- `.font-headline` — Archivo Expanded ExtraBold, uppercase
- `.font-subheader` — Archivo Expanded Medium, uppercase

## Tailwind Font Families

- `font-optic` — Archivo (legacy class name)
- `font-cabin` — Cabin
